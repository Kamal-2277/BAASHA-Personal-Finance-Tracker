How It Is Made

System architecture & pipeline
1. Full-Stack MVC Architecture Incoming browser requests hit Flask routes, which execute business logic, query SQLite databases, and dynamically render Jinja2 templates styled with Tailwind CSS.
2. Dynamic Financial Math & LPA Client-side JavaScript calculates salary and business earnings into Annual LPA in real-time, while Python analytics compute weekly, monthly, and yearly cash flows.
3. Production WSGI Server Engineered with a streamlined Python package footprint and configured with Gunicorn WSGI and Procfile for continuous cloud deployment on platforms like Render.
Pattern: MVC + RESTful API Database: ACID SQLite3
